# Modern Gaming Portfolio

A sleek, modern portfolio website with a gaming aesthetic featuring futuristic design elements, interactive animations, and responsive layout.

## Features

- **Gaming-Inspired Design**: Dark theme with neon accents and futuristic elements
- **Interactive Animations**: Glitch effects, particle systems, and smooth transitions
- **Custom Cursor Trail**: Dynamic cursor with glowing trail effect
- **Loading Screen**: Animated loading sequence with progress bar
- **Responsive Design**: Fully responsive across all devices
- **Smooth Scrolling**: Seamless navigation between sections
- **Skill Animations**: Animated progress bars and counters
- **Project Cards**: 3D tilt effects and overlay animations
- **Contact Form**: Functional contact form with validation
- **Easter Egg**: Hidden Konami code for fun interaction

## Technologies Used

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Custom properties, Grid, Flexbox, animations
- **JavaScript**: ES6+, DOM manipulation, animations
- **Font Awesome**: Icons for enhanced visual appeal
- **Google Fonts**: Orbitron and Rajdhani for gaming typography

## Sections

1. **Hero Section**: Eye-catching introduction with glitch effects
2. **About**: Code block presentation with animated statistics
3. **Projects**: Interactive project cards with hover effects
4. **Skills**: Animated skill bars organized by categories
5. **Contact**: Professional contact form with floating labels

## Customization

### Colors
The color scheme uses CSS custom properties that can be easily modified:

```css
:root {
    --bg-primary: #0a0e1a;
    --bg-secondary: #0f1419;
    --accent-primary: #00ff88;
    --accent-secondary: #ff0080;
    --accent-tertiary: #8000ff;
}
```

### Content
Update the following in `index.html`:
- Personal information in the hero section
- About section code block
- Project details and images
- Skills and percentages
- Contact information

### Images
Replace placeholder images with your own:
- Profile avatar: Update the `src` attribute in the hero section
- Project images: Replace placeholder URLs with actual project screenshots

## Installation

1. Clone or download the files
2. Open `index.html` in a web browser
3. Customize the content to match your profile
4. Deploy to your preferred hosting platform
